如果从微信等应用内打开，请点右上角菜单，选择在外部浏览器打开。苹果使用 Safari，安卓使用 Chrome。
  1. 用 Safari 浏览器打开这个网址。
  2. 点浏览器的分享按钮，再选添加到主屏幕。
  3. 如果出现以网页 App 打开，保持开启，再点添加。
  4. 回到手机桌面，点字母点唱机图标打开。
  1. 用 Chrome 浏览器打开这个网址。
  2. 点浏览器右上角的更多菜单（⋮）。
  3. 选择安装并创建快捷方式，再选安装。部分版本显示为安装应用或添加到主屏幕。
  4. 按系统提示确认，再从桌面或应用列表打开字母点唱机。

首次从桌面打开后，请登录原账号，并确认页面底部显示“离线页面已就绪”。已安装应用与浏览器都使用同一云端曲库，但本机离线副本可能需要各自保存一次。以后联网收到新版提示，点“更新到新版”即可。
