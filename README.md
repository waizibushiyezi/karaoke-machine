# 字母点唱机

正式入口：https://waizibushiyezi.github.io/karaoke-machine/

A–Z 个人曲库、数字点歌、随机盲盒、跨设备同步、离线编辑、手机桌面安装、管理员使用统计、更新公告和软件分享。

## 注册与登录

每个人自行注册账号密码，中文账号名受支持，曲库互不影响。原账号、已同步曲库及现有唯一管理员继续可用，管理员注册保持关闭。GitHub 前端已通过 https://songbox-connectivity-check.onrender.com 的受限连接入口访问账号系统，浏览器不再直接连接原 Sites 域名。

免费服务闲置后可能需要约一分钟唤醒，前端最多等待 90 秒，注册不自动重复提交。若未收到结果，可检查连接并尝试用刚才的账号登录。该免费方案有休眠和资源限制，不能保证所有网络持续可用。

## 手机与离线

苹果用 Safari 分享菜单添加到主屏幕；安卓用 Chrome 安装应用或添加到主屏幕。首次联网登录后等待“离线页面已就绪”，才可断网打开、点歌、抽盲盒和编辑本机曲库。联网后同步，冲突时保留备份并选择版本。建议定期导出曲库。

当前网址和桌面图标继续在线更新，无需重新下载应用。旧网址的本机未同步内容应先同步或导出备份；浏览器清理数据后需重新联网。

## 分享与公告

顶部“分享软件”和登录页“分享给朋友”提供复制入口及可用时的系统分享。链接不携带账号、令牌或私人曲库。管理员为当前构建发布更新公告，用户登录后在合适时机收到弹窗，已读按账号同步。

## 托管与维护

- 本仓库根目录为 GitHub Pages 公共前端，当前构建摘要 8a872747f0e74a15。
- connectivity/ 为 Render 连接服务，白名单路由、来源限制、Bearer 会话、JSON 错误和不缓存私人响应；不转发 Cookie、伪造身份代理头或任意目标地址，不记录密码和令牌。
- 正式数据库、密码哈希、账号认证、角色和同步冲突处理继续在原 Sites 项目维护，不迁入 Render 临时磁盘。Render 实例重启不会清空正式曲库。
- 原站认证及防猜测限流保持生效，多个用户经 Render 出口可能共享上游 IP 限流。扩大规模时需设计有服务认证的分布式限流，不能信任用户提交的 IP 或取消安全限制。
- Render 来自公开仓库，自动发布关闭；修改 connectivity/ 后需手动部署并验证指定提交。发布正式前端前先验证连接服务。
- 原源码项目 scripts/build.mjs 同时生成 Sites Worker 与 pages/，两者使用同一构建摘要。先发布 Sites，再更新本仓库根目录公共文件，以保持公告版本一致。

仓库不保存用户数据库、密码、服务密钥或登录会话。连接测试页不要求输入密码。真实发布验收使用独立测试账号，验证后清空测试歌曲并退出会话。

正式公开网址由 songbox-home 元信息统一配置。即使在旧 Sites 入口打开，分享、系统分享、下载入口、安装指引及复制网址也始终指向 GitHub 正式入口。旧站显示新入口提示，保留其本机曲库并提醒同步或导出；旧站不再调用原生安装，避免新增旧域名图标。

## 好友曲库分享

顶部“分享曲库”生成已同步曲库的分享副本，复制链接给好友。链接使用正式 GitHub 入口和随机能力码，不携带账号或登录信息。好友打开链接并登录后，自动提示“监测到好友曲库分享，是否需要把歌曲加入自己的歌单”。确认后展开字母菜单，默认不勾选任何歌曲，仅将选中歌曲加入本人曲库。只复制链接后从桌面启动时，可点“导入分享”手动粘贴识别。

同字母已有同名歌曲跳过，编号冲突自动使用空闲编号，不覆盖原歌单；重复导入不重复加歌。链接为创建时的副本，之后修改自己的曲库不会改变副本。30 天有效，每人最多 20 个有效链接，作者可在分享记录中关闭。持有链接并登录的人可以查看副本；已导入的歌曲在链接关闭后仍属于接收者。

接口通过受限 Render 网关，均需本人登录。服务端核对分享中的实际歌曲及接收者曲库版本，原子检查并发修改、分享撤销与到期状态。API 不缓存分享内容。正式数据库只追加分享表，不改变账号或管理员。分享和导入需要联网。


## 管理员清理测试账号

管理员可搜索并勾选普通测试账号，核对名单、确认用途并输入“删除测试账号”后执行，一次最多 50 个。删除后移出当前账号及使用统计，登录和分享链接失效；原曲库与账号名保留，可从“已删除账号”选择恢复。恢复需重新登录，旧分享链接不会重新开启。管理员账号受保护，普通用户无此权限；不会自动识别或清理测试账号。设备已有离线副本不能远程清除。

本次升级没有删除任何线上账号。


## 音乐平台歌单导入

顶部“导入音乐歌单”支持 QQ 音乐和网易云公开歌单链接、完整分享文案和官方短链。预览歌名后勾选并选择字母，也可按英文首字母分类；只追加所选歌名、自动编号、同字母同名去重，保留原曲库及同步冲突保护。默认不勾选，平台返回部分结果时明确提示，不保证所有公开歌单一直可完整读取。

无法取到链接或平台受限时，可整批粘贴歌名或预览 TXT / CSV / TSV 文件（最多 2000 首、1 MB），文本 / 文件在本机读取并支持离线导入。仅保存歌名，歌手只在预览显示，不播放或下载音乐。

连接服务先验证当前账号，再以固定官方域名读取公开元数据；不转发软件登录信息，不接收音乐平台密码或 Cookie，不访问私人歌单，不保存作者信息或分享参数，不修改原平台歌单。短链逐跳验证、超时、容量及频率均有限制。平台数据可用性取决于平台与网络。


## 翻页时钟和可选天气

面板显示设备当地年月日、星期与时分秒，变化数字以翻页动画切换；离线也可用，减少动态效果时直接更新，后台暂停并在恢复时校准到设备时间。

天气默认关闭，用户主动选择定位或手动城市后开启。仅将保留一位小数的近似经纬度发送至 Open-Meteo，城市搜索发送输入名称，不附带软件凭据。设置、近似位置与最近天气只保存在本机当前账号，不同步到曲库后台。关闭或退出后清除，取消请求并防止旧定位回调重新开启；不持续追踪位置。

天气约每 30 分钟更新，显示温度、天气和日常提醒。离线 / 更新失败时标明上次天气时间，超过一天不展示旧温度。天气为模型估计，取决于网络与提供方可用性。天气服务署名链接已显示，使用当前免费非商业 API，不新增密钥、数据库或付费服务。


## 历史公告

“更新公告”弹窗可打开“查看历史公告”，没有当前版本公告时直接显示历史。按发布顺序倒序展示，点标题展开全文，可加载更早记录；新公告弹窗和已读同步保留。最近 40 条按当前账号缓存，离线明确提示，联网刷新确认完整列表和撤下状态。

已有各版本仍保留的发布正文迁入历史；此后每次正式发布在同一事务内保存快照，同一版本再次发布也不覆盖旧正文。草稿不公开，撤下该版本公告同时隐藏其历史记录，重新发布不恢复此前撤下记录。功能上线前已被同版后续内容覆盖、数据库已不再保留的旧文字不能自动恢复。普通用户只读，管理员权限维持原设置。


## 专属角落小伙伴

顶部「小伙伴」提供男女四种起始造型、自由换装与配色、名字、左右位置、点击回应、收起和隐藏。装扮按账号保存，离线可改，联网同步；多设备冲突会保留两版并由本人选择。

## 中文拼音分区与批量删歌

音乐歌单导入默认按中文拼音 / 英文字母分区，每首歌显示目标字母；数字开头或无法识别的歌名放入所选字母。可关闭自动分区统一导入。拼音组件 pinyin-pro 3.29.5（MIT）随应用缓存，在本机识别，不外传歌名。多音字按常见词语读音，不自动搬动原有曲库。

曲库管理支持跨字母勾选、全选本分区、清空勾选。删除前按字母列出准确歌曲供确认，未勾选歌曲保留；支持当前设备撤销最近一次删除。撤销只追加已删歌曲，编号冲突自动安排空位，不覆盖后续新增歌曲。删除与撤销可离线保存、联网同步，沿用原有多设备冲突保护。

撤销记录按账号保存在本设备，下一次删除替换记录，退出或清理网站数据时清除；需要长期保存请导出备份。本次不改动任何生产用户的歌曲、账号或公告。验证通过 101 项检查。

## 全曲库盲盒

盲盒面板可切换「当前字母」与「全部曲库」。全部模式将本人 A–Z 的每条歌曲记录放入同一个池等概率抽取，结果保留原字母和编号；当前字母为空也能抽其他分区。歌名仍在点击揭晓后显示。两种范围的本轮不重复记录独立，抽完可重新开始，离线可用。刷新、换账号或更改曲库时相应轮次重置，不同步跨设备抽取进度。完整检查共 116 项通过。

## 歌手查找与盲盒

添加 / 编辑歌曲可填写歌手；QQ、网易云及表格导入保留歌手，预览时可补充修改。功能菜单新增歌手查找；盲盒增加按歌手范围，可跨 A–Z 分区抽取，并在揭晓后显示对应歌手。歌手随离线缓存、同步、备份、好友分享、删除及撤销保留。旧歌未填写的歌手可编辑补充；同一分区按歌名和歌手共同去重。

直播方向：观众发送歌手或数字，由主播通过现有入口手动抽取；尚未接入自动读取直播弹幕。
