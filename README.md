# 字母点唱机

正式入口：https://waizibushiyezi.github.io/karaoke-machine/

A–Z 个人曲库、数字点歌、随机盲盒、跨设备同步、离线编辑、手机桌面安装、管理员使用统计、更新公告和软件分享。

## 注册与登录

每个人自行注册账号密码，中文账号名受支持，曲库互不影响。原账号、已同步曲库及现有唯一管理员继续可用，管理员注册保持关闭。GitHub 前端已通过 https://songbox-connectivity-check.onrender.com 的受限连接入口访问账号系统，浏览器不再直接连接原 Sites 域名。

免费服务闲置后可能需要约一分钟唤醒，前端最多等待 90 秒，注册不自动重复提交。若未收到结果，可检查连接并尝试用刚才的账号登录。该免费方案有休眠和资源限制，不能保证所有网络持续可用。

## 手机与离线

苹果用 Safari 分享菜单添加到主屏幕；安卓用 Chrome 安装应用或添加到主屏幕。首次联网登录后等待“离线页面已就绪”，才可断网打开、点歌、抽盲盒和编辑本机曲库。联网后同步，冲突时保留备份并选择版本。建议定期导出曲库。

当前网址和桌面图标继续在线更新，无需重新下载应用。旧网址的本机未同步内容应先同步或导出备份；浏览器清理数据后需重新联网。

## 分享与公告

顶部“分享软件”和登录页“分享给朋友”提供复制入口及可用时的系统分享。链接不携带账号、令牌或私人曲库。管理员为当前构建发布更新公告，用户登录后在合适时机收到弹窗，已读按账号同步。

## 托管与维护

- 本仓库根目录为 GitHub Pages 公共前端，当前构建摘要 4ae2b4eb8004947f。
- connectivity/ 为 Render 连接服务，白名单路由、来源限制、Bearer 会话、JSON 错误和不缓存私人响应；不转发 Cookie、伪造身份代理头或任意目标地址，不记录密码和令牌。
- 正式数据库、密码哈希、账号认证、角色和同步冲突处理继续在原 Sites 项目维护，不迁入 Render 临时磁盘。Render 实例重启不会清空正式曲库。
- 原站认证及防猜测限流保持生效，多个用户经 Render 出口可能共享上游 IP 限流。扩大规模时需设计有服务认证的分布式限流，不能信任用户提交的 IP 或取消安全限制。
- Render 来自公开仓库，自动发布关闭；修改 connectivity/ 后需手动部署并验证指定提交。发布正式前端前先验证连接服务。
- 原源码项目 scripts/build.mjs 同时生成 Sites Worker 与 pages/，两者使用同一构建摘要。先发布 Sites，再更新本仓库根目录公共文件，以保持公告版本一致。

仓库不保存用户数据库、密码、服务密钥或登录会话。连接测试页不要求输入密码。真实发布验收使用独立测试账号，验证后清空测试歌曲并退出会话。

正式公开网址由 songbox-home 元信息统一配置。即使在旧 Sites 入口打开，分享、系统分享、下载入口、安装指引及复制网址也始终指向 GitHub 正式入口。旧站显示新入口提示，保留其本机曲库并提醒同步或导出；旧站不再调用原生安装，避免新增旧域名图标。

## 好友曲库分享

顶部“分享曲库”生成已同步曲库的分享副本，复制链接给好友。链接使用正式 GitHub 入口和随机能力码，不携带账号或登录信息。好友打开链接并登录后，自动提示“监测到好友曲库分享，是否需要把歌曲加入自己的歌单”。确认后展开字母菜单，默认不勾选任何歌曲，仅将选中歌曲加入本人曲库。只复制链接后从桌面启动时，可点“导入分享”手动粘贴识别。

同字母已有同名歌曲跳过，编号冲突自动使用空闲编号，不覆盖原歌单；重复导入不重复加歌。链接为创建时的副本，之后修改自己的曲库不会改变副本。30 天有效，每人最多 20 个有效链接，作者可在分享记录中关闭。持有链接并登录的人可以查看副本；已导入的歌曲在链接关闭后仍属于接收者。

接口通过受限 Render 网关，均需本人登录。服务端核对分享中的实际歌曲及接收者曲库版本，原子检查并发修改、分享撤销与到期状态。API 不缓存分享内容。正式数据库只追加分享表，不改变账号或管理员。分享和导入需要联网。


## 管理员清理测试账号

管理员可搜索并勾选普通测试账号，核对名单、确认用途并输入“删除测试账号”后执行，一次最多 50 个。删除后移出当前账号及使用统计，登录和分享链接失效；原曲库与账号名保留，可从“已删除账号”选择恢复。恢复需重新登录，旧分享链接不会重新开启。管理员账号受保护，普通用户无此权限；不会自动识别或清理测试账号。设备已有离线副本不能远程清除。

本次升级没有删除任何线上账号。
